# ChatGPT Platform

- Platform id: `chatgpt`
- Registry config: [`../../platforms/chatgpt.json`](../../platforms/chatgpt.json)
- Display name: `ChatGPT`
- Default enabled: yes

## URLs

- Start URL: `https://chatgpt.com/`
- Canonical conversation URL: `https://chatgpt.com/c/<id>`

## Export notes

Use the user's already logged-in browser session. Do not export cookies, bypass login, or work around CAPTCHA/login controls.

## QA notes

Markdown message headings produced for this platform should use the `ChatGPT` assistant label declared in the registry.
